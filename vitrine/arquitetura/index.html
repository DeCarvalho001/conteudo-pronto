▸ Como o dinheiro é feito

Da barbearia na rua até a assinatura paga. Cada passo tem ferramenta própria.

① Achar e preparar o alvo
  1. Comandante manda link/print da barbearia (Maps/Instagram)
  2. visao_negocio lê o print · coletar_fotos + negocio_google puxam fotos/dados reais
  3. ficha salva em /opt/data/kits/<slug>.json (fonte única)
  4. territorio.checar avisa se o bairro já está reservado
② Montar o kit (o presente)
  1. site_barbearia.build(ficha) → site premium (tema pela vibe do alvo)
  2. paginas_barbearia.build_subsite → /servicos/ /galeria/ /avaliacoes/
  3. plano_cliente → diagnóstico 'Mata a Falta' em <slug>.omnisdata.app/plano/
  4. prospectar → mensagem de abordagem (só fatos da ficha)
  5. dominio_cliente → liga <slug>.omnisdata.app no Cloudflare
③ Vender
  1. Comandante manda o 'oi' no WhatsApp com o site de presente
  2. followup/guardiao_acao cobram a cadência; copiloto ajuda ao vivo
  3. barbeiro clica o plano → link Asaas (assinatura R$147/247/397)
④ Entregar e reter
  1. territorio.reservar trava o bairro (1 barbearia por bairro)
  2. avaliacoes · cardapio · cartao_digital · clube_montador · posts/calendario
  3. atendente_telegram (bot que agenda e cobra sinal no Pix)
  4. financeiro registra o MRR
🚪 A porta de entrada é uma só: kit_links.py <url1> [url2...] — o Comandante manda os links da barbearia e o sistema faz o resto (fotos, site, diagnóstico, mensagem).

▸ Regras de ouro

Cada uma custou tempo real de debug ou quase deu dano em produção. Ler antes de mexer.

ZERO invenção: número/preço/nota só com fonte real; seção sem dado não aparece.
Site do cliente só com foto REAL dele. Stock (Pexels) é só no site-MODELO fictício.
Site-modelo fictício = banner de demonstração + noindex + SEM schema de avaliação.
NUNCA testar em slug de produção (sobrescreve site publicado).
Script no VPS sempre via arquivo (scp → docker cp → exec). Heredoc aninhado falha SILENCIOSO.
Depois de docker cp num módulo: apagar __pycache__/<mod>* antes de re-rodar quem o importa.
GitHub Pages: URL com barra final (sem = 301). Deploy novo demora 1-2 min (CDN).
Verificar na FONTE (API do GitHub), não no raw.githubusercontent (cacheia ~5 min).
Segredo (.env) nunca sai em log/página — só o NOME da variável.
1 barbearia por bairro (exclusividade) — territorio.py é a trava.

▸ Para o próximo agente

A mesma verdade em máquina: arquitetura.json — com importa/importado_por de cada módulo, fluxos, regras e superfícies. Cole esse arquivo no começo de uma sessão nova e o agente já entende o sistema inteiro.

Como usar:
Vai mexer num módulo?Olhe importado_por — é a lista do que pode quebrar. Vai criar peça nova?Veja o fluxo em que ela entra e reuse os helpers de site_negocio.py. Vai publicar?Barra final na URL, e confira na API do GitHub (o raw cacheia 5 min). Regenerar este mapascan_arq.py → build_arq.py (leem o código de novo).
